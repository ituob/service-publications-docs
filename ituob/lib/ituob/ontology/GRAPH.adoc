== Edge gates (every arrow is enforced)

[cols="2,3"]
|===
| Edge | Gate

| parse (itu-ob-data → instances) | `verify_parser_equivalence.rb --verify` (CI)
| instance YAML shapes | `validate_data_lml.rb` (CI, validate-ob-issues)
| dataset files | `ituob dataset validate` 40/40 (CI)

== Definability status

[cols="1,3,1"]
|===
| Layer | Meaning | Status
| Class shapes (84) | Every attribute, type, cardinality, default declared in messages.lml | DONE — drift guard fails on divergence
| Class execution | Pure data-shape classes compiled from the LML at boot (Compiled::CLASS_NAMES = 44) | DONE for all constraint-free classes; E118Action (anonymous-type constraint), DPEntry (semantic hierarchy), Change/ChangeSet/OldIssue/GeneralMessage + per-publication Amendment parsers remain hand-written by design — shapes still LML-guarded
| Instance data (YAML) | ob-issues + messages + datasets validate through the compiled classes | validate_data_lml.rb (this PR) — CI
| Instance syntax (LML) | .lml instance documents as an alternate serialization | capability exists in lutaml-lml (hydrate / Format adapter); pipeline deliberately speaks YAML
|===
