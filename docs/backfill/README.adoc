= Backfill inventory and evidence probe

Part of ituob/service-publications-docs#149.

== Inventory

`docs/backfill/inventory.yaml` is generated by `scripts/build_backfill_inventory.rb`.

== Evidence probe (maintainer step, needs network)

Agent lanes have no network, so the live probe is run by a maintainer:

[source,sh]
----
ruby scripts/build_backfill_inventory.rb        # regenerate; this discards earlier probe rows
ruby scripts/probe_backfill_sources.rb --delay 1.5
----

For every entry the probe tries the publication page
`https://www.itu.int/pub/T-SP-OB.<no>-<year>` and the `dms_pub` files
`T-SP-OB.<no>-<year>-OAS-MSW-E.doc`, `-MSW-E.docx` and `-PDF-E.pdf` (then the `F` and `S`
variants) for the estimated year, year -1 and year +1.

* One request at a time, `--delay` seconds apart (default 1; use 1.5 or more), HEAD before GET
  (GET only when HEAD is refused with 403/405/501), 429/5xx retried with exponential backoff.
* Answers are cached in `docs/backfill/probe_cache.json`; an interrupted run resumes and a
  rerun skips answered URLs. Delete the cache to re-check. Requests that still fail with
  429/5xx after the retries are not cached.
* Each tried URL is appended to the entry's `evidence` as `url`, `status`, `content_type`,
  `checked_at`.
* A 200 for an English MSW/PDF file (not `text/html`) moves `unresolved` to `b` and sets
  `source_url`. Any other 200 (the page, a French or Spanish file) is listed under
  `candidates` only: classes c and d are decided in the human review step.
* `--only 700,701` and `--limit N` restrict a trial run.

The inventory spec compares the committed `inventory.yaml` with the generator output, so the
probe-annotated file cannot be committed unchanged. Change that spec in the same PR as the
live-run results.
