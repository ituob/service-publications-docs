= Typed provider migration preservation proof
:!sectnums:

All 38 `yaml2text` rows and the one mixed row from the coverage matrix at
`8f19d30cb7264593a90f768de3e32746061225a3` now use typed provider sources.
The 22-publication, 87-language-edition inventory has no remaining file-injection data blocks.
Dataset snapshot queries keep the original issue, every row in order, repeated identifiers,
nested country sidecars, scalar types and localized metadata. They do not replay later changes.

Column labels are supplied through the provider in English, French and Spanish,
and Arabic, Russian and Chinese for the six-language E.212 publications.
Existing F.32 labels also now come from its provider metadata.
Missing labels and the SR.1 French/Spanish header correction are declared in
`ituob/lib/ituob/projections/*labels.yaml`; the corpus is unchanged.

== Rendered AsciiDoc comparison

`ituob/spec/metanorma/remaining_provider_documents_spec.rb` expands complete
AsciiDoc documents using their Liquid partials and data sources. The baseline
was captured before migration, including the RR.25.1 `loadfile` country rules.
The committed `remaining_main_sha256.json` fixture records the base commit,
complete before/after SHA-256 values, exact intended substitutions and occurrence counts.
It checks every output byte; reversing only the explicit substitutions must recover
the original digest. There is no whitespace normalization and no PDF rendering.

== Focused validation and CI

Focused document, template, manifest, dataset, label, ontology and coverage specs pass.
`scripts/verify_parser_equivalence.rb --verify` reports all 15 parser families equivalent.
Run focused specs with `--options /dev/null -Iituob/spec -r spec_helper` to avoid
the repository-wide pattern in `.rspec` expanding a file-selected invocation.

The existing `pdf` workflow still runs its `official-comparison` job after rendering.
This migration does not weaken the gate or regenerate its official baseline.
Its reference coverage remains one official PDF, F.32 2011 English; other references
are absent as documented in `official-comparison.adoc`. CI results must be evaluated
at the pushed PR head; local AsciiDoc preservation is not a claim of a passing hosted job.

NOT RUN locally: completed full suite, full site build, or PDF rendering.
RuboCop was unavailable in the required gem bundle; syntax checks and `git diff --check` pass.
Initial file-selected RSpec commands expanded through `.rspec` and were stopped;
the reported test evidence uses the explicit focused options above.
