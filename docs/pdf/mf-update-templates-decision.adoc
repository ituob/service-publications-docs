= Decision: `mf-update-templates` is already on main

Part of spd#89, task 2 ("Land or supersede `mf-update-templates`").

== Decision

Supersede. Nothing is ported. The branch `origin/mf-update-templates` holds one
commit, `114d2858` ("feat: Use `loadfile` within render tag", 2025-05-12). Its
patch-id (`git patch-id --stable`) is identical to `29e5819c` on main (spd#50),
so the commit was already landed as a rebased copy. The old branch is left in
place; deleting it is a separate decision.

== Why nothing is ported

`git diff origin/main origin/mf-update-templates -- documents/T-SP-RR.25.1-2018`
differs only in the two `item.description` lines that main added after the
branch was cut. The later main work (spd#117, spd#118, #102 per-language
labels, the provider data path for F.32 and E.212B) touches other files and
does not conflict with this commit.

== Fidelity

Not measured, because no template changed: a CI render of this branch would be
byte-for-byte the render of main for RR.25.1.
