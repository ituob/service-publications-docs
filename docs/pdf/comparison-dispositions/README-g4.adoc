== Shape fixes (ours, no disposition)

* T.35: a wrapped country name is any line indented 28+ columns directly under a row (fixed S: 1 -> 0).
* SR.1: a block whose three name lines are split by a page break (stub at the page foot) is joined
  to the chunk after the break; the note regex accepts a "1.1." prefix; the preface ends at the table header.
  Premise disproved: the generated PDF does carry the TSB preface note, the earlier "missing note" was a shape bug.
* X.121B: a wrapped network name where the generated PDF puts country text on the same line; multi-digit
  and ranged codes (`260 621`, `230 40-44`, `460 200-207`); lone-code lines; lower-case running text is not a network name.
* RR.25.1: permitted/forbidden is decided by the leftmost x of each page plus a gap of 3 columns
  (the official PDF has exactly two forbidden rows, Korea DPR and Eritrea, in all languages; the earlier
  column logic gave 29/4/14 generated forbidden rows); part 2 opens at its heading after page furniture.

== Confirmed bugs in the generated PDFs

* T.35: the escape-code row prints "See Note." without the note number (E and F).
* T.35B: "N/A" entries missing; French label "des informations" wrong; "Dirección General" dropped (Spanish).
* X.121A E: the asterisk and the footnote "* Formerly CCITT Recommendation" are dropped.
* X.121B: a multi-digit or ranged code cell wraps (`230 40-/44`, `260/621`, `460/200-207`); the "1)" footnote marker
  is dropped in 4 rows (20 bug deltas per language).
* RR.25.1: call-sign patterns print as regular expressions; in F and S the generated forms use English
  labels ("Amateur stations", "Experimental stations") instead of the language of the PDF.

== Unreviewed (counted, not settled)

* T.35B tail: E 7, F 13, S 13. Swiss URL glue, "Regulation"/"Régulations", Mauritius "Prot-Louis",
  form-question wrap differences. Not looked at one by one.
* SR.1-F: 1, the Hong Kong block (CT2 text merged with the next block).
* RR.25.1: E 64, F 83, S 77 open. These are call-sign form blocks the rules do not cover: forms that
  exist only in the generated PDF (E 15, F 52, S 40 rows in the full delta list) or only in the official PDF
  (E 14, F 31, S 34), and rows that differ beyond the three rules. The generated-only blocks for French,
  Spanish and Japanese countries are bug candidates (generated forms for administrations the official
  PDF gives no form for), not confirmed. A call-sign forms row with no rule stays open.
