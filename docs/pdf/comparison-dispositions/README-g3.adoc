== What changed in the shapes (our parsing mistakes, fixed in code, not dispositioned)

* F.68: preface ends at the `TDC|CTD` table header; ordinal markers (`ª`, `º`) accepted on TDC codes; a
  second network code printed under the first (RU over SU) is merged into the row.
* F.1: preface runs from "Note from the TSB" to the Part I heading.
* PP.RES.21: the list is two columns per line (split on 3+ spaces); a row is keyed by the country name,
  its text is the number, rows sorted by name.
* M.1400: `prose_stop` at "Country or area" (the whole table was being compared as prose, the cause of
  the 3.3 GB run); a row is the bag of its words; left margin 4 (official pages are indented 3); page
  marker tightened so a street "21-24-26" is no longer dropped as a footer; header continuation drops
  header vocabulary only, so a row split by a page break is kept.

== Rules behind the dispositions (each checked on samples, generated by scratch `gen3.rb`)

* layout, hyphen: official hyphenates at a line end ("word- word" vs "wordword").
* layout, moved: same text in both PDFs at different positions (prose block order, row position within
  Part II, F/S country order in M.1400).
* layout, footer / "N°" vs "No": running page footers; abbreviation of "number".
* data, F.68 TDC 592: the official PDF has footnote "h) Reserved"; the dataset has none.
* data, PP.RES.21 F/S: the dataset keeps English alphabetical numbering; the official F and S lists
  number in their own language (generated number equals the dataset number for every dispositioned row).
* data, PP.RES.21 E: dataset lists Bulgaria 117 and Lithuania 118; official E stops at 116 (official F
  prints Bulgarie). Flag for a human: which edition the dataset follows.
* data, M.1400: the official row has telephone / e-mail lines the dataset record does not have.
* data, F.1: generated text equals the dataset; the official PDF has a one-word typo.

== Confirmed bugs (generated PDF or dataset)

* F.68-F, F.68-S Annex B: the dataset `datasets/978-F.68-A2` has the fr and es names swapped in many rows
  (e.g. OB 770 fr "Haití", es "Haïti"); the generator renders them as stored (37 rows each; the rows are
  matched against any record of a duplicated OB number).
* F.68-S: abbreviation prints "VTRVTR Telecomunicaciones S.A." (one word at x 56-100, pdftotext -bbox).
* F.68-F: abbreviation "TELEX CHILE" is split into "TELEX" and "CHILE Télex Chile ..." over two cells.
* F.1-F: the generated Part II repeats a block of the "Adresses" field (10 extra rows, e.g. II:ATFIX).
* M.1400 E/F/S (7/6/4 rows): the generated PDF omits `address_line_3` (e.g. IOT "(United States)",
  present in the dataset and in the official PDF; measured: 0 vs 4 occurrences in the E text).
