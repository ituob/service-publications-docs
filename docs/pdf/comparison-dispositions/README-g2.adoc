== Rules (each checked on samples before use)

order_en / order_gen_en::
Alphabetical lists and country sections. In A, C, R the official PDF lists the alphabetical list in the order of the English names
(its code order equals the official English PDF; at least 97% of its rows in longest common order), the generated PDF in the
language's own order: `layout`. In E.212B and Q.708B F and S the generated PDF lists countries in the English-name order (its
row order equals the generated English PDF) while the official PDF is in the language's own alphabetical order (99-100% of its country
headings in folded order; the generated F puts "Samoa americaines" after "Algerie", the official PDF files it under S): `bug`.
collation::
E/F/S alphabetical lists: the generated list is sorted by code point (capitals first, accented letters after z); the official PDF sorts
ignoring case and accents: `bug`.
dropped::
Q.708A alphabetical list: the code occurs once in the generated text (numeric list only) and twice in the official one: `bug`.
25 rows in E, F, R, S (8 shown as delta in A).
formerly::
The generated PDF drops the "(Formerly ...)" annotation (E.212A shared 901 rows, E.212B networks): `bug`.
group_order::
Rows of one name keep the official PDF's own code order (316 down to 310): same rows, `layout`.
glyph, wrap_status, p_ws, p_listnum::
Arabic letter-order extraction artefact (same letters), a Chinese status cell wrapped over two lines, whitespace or hyphenation only,
bare list digits in the official preface: all `layout`, same text.
data_name, e10, off_omits::
`data`: the generated name is the dataset's name for that code (datasets/1117-E.212A, 1125-E.218, 1125-Q.708A); the dataset holds
`10000000000000` where the official PDF prints `1000E10`; the row is missing in the official Arabic/Chinese PDF but is in the English PDF and the dataset.

== Confirmed bugs in the generated PDFs (disposition `bug`)

. Q.708A alphabetical list drops 25 rows (Hong Kong 16, Macao 2, Taiwan 5, Saint Helena 2) in E, F, R, S.
. "(Formerly ...)" dropped: E.212A shared 901 rows (E, F, S: 4 each), E.212B networks (C, E, F, S: 3 each).
. Code-point collation in the E, F, S alphabetical lists (E.212A, E.218, Q.708A).
. E.212B and Q.708B country order follows the English names in F and S.
