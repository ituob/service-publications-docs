== Method

[source,sh]
----
metanorma -t itu -x pdf T-SP-F.32-2011-E.adoc        # in documents/T-SP-F.32-2011
ruby scripts/compare_official_pdf.rb GENERATED.pdf OFFICIAL.pdf \
  --data datasets/980-F.32/data.yaml --out OUTDIR
----

Both PDFs go through `pdftotext -layout`; whitespace, curly quotes and case are
normalised. Two layers are diffed with a longest-common-subsequence diff:

rows:: Every layout line ending in a 4-character office code is a table row,
keyed on that code. Names wrap differently in the two PDFs, so a name is only
cross-checked leniently (equal after normalisation, one a prefix of the other,
or both fragments of one dataset name).
prose:: The preface words from "Note from TSB" up to the first table header,
list markers removed.

`--data` lets the script settle a missing row by measurement: a row absent from
the generated PDF is *data* if the dataset has no such record and a *bug* if it
does; a dataset record that never reaches the generated PDF is a *bug*. Codes
are not unique (the `--XX` codes are reused), so such a row counts as "in the
dataset" only when the code and a name match, and a row whose code and name
occur more than once is left for hand review.

== Findings that matter

. *The F.32 dataset is incomplete, not the generator.* All 823 data deltas are
rows the dataset lacks (Italy onward, plus Belarus). Fixing it is a data
task; no PDF fix will close it. Until then a generated F.32 PDF is 33 pages
against the official 47.
. *Fidelity of what is there is good.* Row order, office codes and names match
for all 676 rows; prose matches word for word apart from markers and spacing.
. *Out of scope here (C13).* The comparison is text and table content only. It
does not see layout fidelity (cover, header/footer, fonts), and the generated
cover differs visibly ("ITUPublications", "2011 edition" versus the official
"Annex to ITU Operational Bulletin No. 980 - 15.V.2011").

== Limits of the tool

* `pdftotext -layout` row parsing, not a PDF table extractor: a name wrapped over
several lines is matched leniently, so a changed word in the middle of a
wrapped name is not caught unless a code differs.
* English only; the country column is trilingual and is not compared.
* The tool reports disposition `unreviewed` for anything its rules cannot
settle; this run had 9, all dispositioned above by hand.
* Scaling to other publications needs their official PDFs (blocked on C9) and
a row definition per table shape.
