== Result and boundary

The local source contains one genuine printed `DEL` action: Sweden in OB 1335,
Q.708 ISPC. The existing corpus stores that heading and its three deleted codes
inside an `ADD` patch under Spain. Natural-language deletion, withdrawal and
cancellation wording also occurs beside genuine printed `SUP` actions. Keep those
as `SUP`; the English word “delete” does not establish that the bulletin printed
`DEL`.

This audit compares the local source submodule at
`90f99728acd1e96d025ce0034fe43a38b572aa62` with the corpus/parser at
`0651a679b0180d7bdc611d7c72756f64a0dd52a0`. No source or corpus patches were changed.
Every `path:line` below refers to a physical line of the local YAML or AsciiDoc
transcription of the printed bulletin. These are not PDF page or printed line
numbers; the local source does not supply printed line numbering. Quoted wording
is from that transcription.

== Reproduction and scope

Search all 1,439 YAML and 104 AsciiDoc files recursively under
`itu-ob-data/issues`, including general communications, amendments and reference
AsciiDoc. Source hit counts are lexical occurrences by physical line, not counts
of distinct deletions. YAML and AsciiDoc may describe the same event.

[source,shell]
----
rg -n -i '\b(delete[ds]?|deletions?)\b' itu-ob-data/issues -g '*.yaml'
rg -n -i '\b(withdrawn|withdrawal|withdrawals|cancelled|canceled|cancellations?|removed|removal)\b' itu-ob-data/issues -g '*.yaml'
rg -n -i '\b(delete[ds]?|deletions?|withdrawn|withdrawal|withdrawals|cancelled|canceled|cancellations?|removed|removal)\b' itu-ob-data/issues -g '*.adoc'
rg -n '\bDEL\b' itu-ob-data/issues -g '*.yaml' -g '*.adoc'
----

The first three searches return respectively 45 YAML lines, 556 YAML lines and
19 AsciiDoc lines. The grouped inventory below accounts for all 601 YAML lines
and all 19 AsciiDoc lines. The separate case-sensitive `DEL` search is adjudicated
as an action only where it heads amendment rows; uppercase `DEL` in names such
as `NEXTEL DEL PERÚ`, addresses and place names is not an action. Lowercase
Spanish/Italian `del`, `Del Fresno`, and URLs containing `/del-` are likewise not
deletion instructions. The inventory is exhaustive for these explicit English
terms in this local source snapshot, not for every possible paraphrase or other
language.

Grouping uses each hit's containing `messages` YAML element. Its `type` and
`target.publication` select the corpus directory; payload `type` is read from the
actual files, independently of filename suffix. Reproduce the grouping by reading
those enclosing message elements and the listed directory's `*.yaml` payloads.
The table lists every matched physical line, including repeated column headers.
A directory's type summary describes its current patches; it does not assert that
every row in that directory has the same intended action.

== Classification rule and c7 rebuild inventory

`Amendment.action_keyword_in` (`ituob/lib/ituob/models/amendment.rb:33`) and
`Catalogs::ActionTypes.keyword_regex` / `find_last_in`
(`ituob/lib/ituob/catalogs/action_types.rb:40,58`) recognize printed
`ADD SUP REP LIR MOD DEL`. They do not turn deletion prose into `DEL`.
`codemap.py action_keyword_in find_last_in` traces the callers, including the
ProseMirror extractor, text amendment content and action splitter. Q.708 and
E.212 use their publication parsers, so keyword catalog support alone does not
prove that a printed heading reaches the correct output action.

`Strategies::Sup` removes the entry, records `deleted_keys`, and can record a
supersession redirect. `Strategies::Del` removes the entry, records `deleted_keys`
and clears a lapsed marker. Therefore printed `SUP` can already mean deletion;
relabeling every English deletion as `DEL` would change replay semantics.

The following are confirmed corpus rebuild targets, not changes made by this
audit. Regenerate the complete publication patch sequence so deleted rows and
subsequent `ADD`/`LIR` replacements keep their ordering and country context.
