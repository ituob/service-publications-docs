= G7: seed-issue replay proof

Issue: ituob/service-publications-docs#84.
Comparison baseline: main at `26cc6fae`.

== Exclusion contract

A catalogued post-amendment annex permits exclusion of a same-issue ADD or
LIR only when every keyed patch row is present and every field the patch
sets has the same value in the seed. Hashes are compared recursively: extra
seed translations are preserved, but missing or differing patch fields prevent
exclusion. Arrays and scalar values must match exactly. A SUP is excluded only
when every target is absent. Unknown actions, unkeyed content and missing seeds
retain replay. A key touched by an earlier retained seed-issue patch also
retains replay, so a SUP followed by an otherwise identical ADD restores it.
Pre-seed and later-issue behavior is unchanged.

Patches with missing or differing fields are replayed in full using the existing
ADD/LIR update behavior. The printed amendment is the authority for the fields
it carries, including differently split addresses and effective dates. This
avoids inventing equivalences between different printed field values.
Namibia's `1161-0005-ADD-89_264_33.yaml` therefore preserves
`effective_date: 1.VII.2018`, which is absent from the annex seed.
