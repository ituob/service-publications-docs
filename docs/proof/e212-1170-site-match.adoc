= E.212 proof document vs site data at OB 1170

Question: do the rows of `e212-1170.adoc` (rendered by `check_e212_1170.rb`)
match what the site shows for `e212-mnc` at issue 1170
(`/registers/e212-mnc/at/1170/`, which reads `data/snapshots/e212-mnc/at-1170.json`)?

== Method

Base: service-publications-docs `origin/main` 2c0dae9c (includes PR #101).

. Proof side: `cd docs/proof && bundle exec ruby check_e212_1170.rb`
  printed `RESULT PASS: 1987 rows, as_of_issue 1170` (metanorma-plugin-lutaml 0.7.71).
  Rows were read from the generated Metanorma XML (`//table//tbody/tr`).
. Site side: the snapshot the site route reads, generated by
  `SNAPSHOTS_OUT=<dir> bundle exec ruby -rituob scripts/generate_register_snapshots.rb E212_MNC`
  (1 register, 162 files, 0 errors). `at-1170.json` is byte-identical to
  `ituob.org-v2/data/snapshots/e212-mnc/at-1170.json`.
. Provider side: `Ituob::Provider.new.edition(register: "e212-mnc", as_of: 1170).items`
  as (mcc_mnc_codes, networks, country_or_area.en).

== Result

[cols="2,1,3"]
|===
| Comparison | Rows | Result

| Site snapshot `entry_count` | 1987 | active entries, 0 lapsed, 0 deleted
| Provider items vs site snapshot, (MCC+MNC, operator, country en), ordered | 1987 / 1987 | identical, 0 differences
| Proof document rows vs site snapshot, (MCC+MNC, operator), ordered | 1987 / 1987 | same keys and order; 41 operator strings differ in typography only
|===

The 41 differing strings are Asciidoc inline substitutions applied by the
proof render, not data differences:

* 19: ` - ` becomes an em dash (for example `Vodafone - Panafon`)
* 21: straight quotes and apostrophes become curly (for example `"Azercell Telecom" LLC`, `Orange Côte d'Ivoire`)
* 1: `Ericsson *test use only*` renders as italic `Ericsson test use only` (`206 33`)

After normalising dashes, quotes and the one italic span, the proof rows equal
the site rows (0 residual).

The proof document has no country column (columns are MCC+MNC and Network), so
country was compared through the provider (see the table above).
