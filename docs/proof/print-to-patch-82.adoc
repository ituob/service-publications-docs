== Preservation behavior

* Roman-numeral, compact and semicolon-separated E.164 date footnotes retain
  their printed strings. A shared marker applies to all pending matching
  actions; consuming a definition prevents a later reused marker overwriting it.
* OB 1161 prints two dates in a single footnote without per-row keys. The exact
  two-date string is retained with the marked rows and amendment notes; no
  unprinted per-row date assignment is inferred.
* Both numerical/alphabetical South Sudan announcements retain code 211,
  country name and their printed action positions. The withdrawal introduction
  remains register amendment metadata in the action patches.
* E.212 repeated marker definitions close their preceding announcement group.
  An explicit different marker prevents the unmarked-preceding fallback.
  OB 1210 retains the code/action heading without inventing a network row.
  OB 983 loses only the earlier group's incorrectly attached date note;
  its own date remains. OB 981's SUP 1 date remains with 901 25, not Australia.
* ActionSplitter leaves already separated printed actions intact, preserving
  metadata and notes. ActionMerger removes only the files of the group being
  merged, preserving other action groups and their entries.
